= Embed a Liveboard
:toc: true
:toclevels: 2

:page-title: Embed Liveboards
:page-pageid: embed-liveboard
:page-description: You can use the LiveboardEmbed SDK library to embed a ThoughtSpot Liveboard in your app and use it for live insights

This page explains how to embed a ThoughtSpot Liveboard in your web page, portal, or application.

A ThoughtSpot Liveboard is an interactive dashboard that presents a collection of visualizations pinned by a user.

== Import the LiveboardEmbed package

Import the `LiveboardEmbed` SDK library to your application environment:

**npm**
[source,JavaScript]
----
import {
    LiveboardEmbed,
    AuthType,
    init,
    prefetch,
    EmbedEvent
}
from '@thoughtspot/visual-embed-sdk';
----

**ES6**
[source,JavaScript]
----
<script type = 'module'>
    import {
        LiveboardEmbed,
        AuthType,
        init,
        prefetch
    }
from 'https://cdn.jsdelivr.net/npm/@thoughtspot/visual-embed-sdk/dist/tsembed.es.js';
----

== Initialize the SDK

xref:getting-started.adoc#initSdk[Initialize the SDK] and define authentication attributes.

== Create an instance of the LiveboardEmbed class

[source,JavaScript]
----
const liveboardEmbed = new LiveboardEmbed(document.getElementById('ts-embed'), {
    frameParams: {
        width: '100%',
        height: '100%',
    },
    liveboardId: '<%=liveboardGUID%>',
});
----

For more information about the Liveboard embed object, classes, methods, interface properties, and enumeration members, see the following pages:

* xref:LiveboardEmbed.adoc[LiveboardEmbed]
* xref:LiveboardViewConfig.adoc[LiveboardViewConfig]
* xref:Action.adoc[Actions]

== Customize Liveboard view

The `LiveboardEmbed` component includes the `xref:LiveboardViewConfig.adoc[LiveboardViewConfig]` object. This object provides various attributes and properties to xref:css-customization.adoc[customize the look and feel of the Liveboard page], xref:embed-actions.adoc[control the visibility of menu actions] and features, and xref:embed-events.adoc[manage interactions between the host and embedded app].

The most common customization is controlling the visibility of menu items in the embedded view by configuring the `disabledActions`, `hiddenActions`, and `visibleActions` properties with an array of xref:Action.adoc[Action] IDs. For information about the other frequently used properties, see <<common-customizations,common customization options>>.

== Register, handle, and trigger events

Register event listeners.

[source,JavaScript]
----
liveboardEmbed.on(EmbedEvent.init, showLoader)
liveboardEmbed.on(EmbedEvent.load, hideLoader)
----

For more information about events, see the following pages:

* xref:HostEvent.adoc[HostEvent]
* xref:EmbedEvent.adoc[EmbedEvent]
* xref:embed-events.adoc[Events and app integration]

== Render the embedded Liveboard

Render the embedded Liveboard.

[source,JavaScript]
----
liveboardEmbed.render();
----

== Common customization options
The *xref:LiveboardViewConfig.adoc[LiveboardViewConfig]* object includes several properties and attributes that allow fine-grained control of the embedded experience. You can specify settings that enable or disable a specific feature, control visible or disabled menu elements and actions, set tabs and layout preferences, manage filters, hide the header, and more.

The customization options are grouped into the following pages:

[width="100%",cols="2,4",options="header"]
|====
|Page |Customization impact
|xref:customize-liveboard-layout.adoc[Customize Liveboard layout and UI]
|Header visibility and compact header, tabs, visible tabs and visualizations, tile gutter, Note tiles, responsive breakpoints and 12-column layout, and grouping and styling.
|xref:customize-liveboard-filters.adoc[Customize Liveboard filters]
|Filter chip visibility, masked filter chips, filters at load time, contextual filtering at the Liveboard, tab, and group levels, and updating filters with host events.
|xref:liveboard-overrides.adoc[Set filter and parameter values at load]
|Values of existing filter and parameter chips at load, through `liveboardOverride` or the Liveboard URL, with targeting by model, tab, or group.
|xref:liveboard-data-downloads.adoc[Customize data refresh and download options]
|Browser data cache and refresh, PDF, XLSX, and CSV downloads, download action IDs and host events, and scheduled exports.
|====

[IMPORTANT]
====
If a Liveboard is saved with Groups in the ThoughtSpot interface, you must set `isLiveboardMasterpiecesEnabled` to `true` in your embed configuration. Otherwise, the embedded Liveboard fails to load. For more information, see xref:customize-liveboard-layout.adoc#liveboard-grouping-styling[Liveboard grouping and styling].
====

[#personalized-views]
== #Embed a personalized view#

#A personalized view is a saved configuration of a Liveboard that includes the filter selections and changes applied by a user. To load a personalized view, specify its GUID in `personalizedViewId` along with `liveboardId`.#

[source,JavaScript]
----
const liveboardEmbed = new LiveboardEmbed(document.getElementById('ts-embed'), {
    liveboardId: '<%=liveboardGUID%>',
    personalizedViewId: '<%=viewGUID%>',
    isPersonalizedViewsSharingEnabled: true,
});
----

[NOTE]
====
#The `personalizedViewId` parameter supports any personalized view the user has access to, including:#

* #Views created by the user (private or public)#
* #Views made public by other users#
* #Views shared with the user or their groups by other view authors#

#The user does not need to be the author of the view. If a view is shared with the user via the `POST /api/rest/2.0/security/metadata/share` API or through the ThoughtSpot UI, it can be loaded using `personalizedViewId`.#
====

=== #Share personalized views#

#To allow users to share personalized views with specific users and groups in the embedded app, set `isPersonalizedViewsSharingEnabled` to `true` in the `LiveboardEmbed` or `AppEmbed` configuration. If this flag is not set, the embed follows the setting on your ThoughtSpot instance, which is off by default.#

#When sharing is enabled, the *Manage views* dialog shows a *Share* option on the views a user can manage and a *Shared with you* tab, and users can share a view when they save it.#

#You can control the sharing options in the embedded view using the following:#

* #Action IDs: `Action.SharePersonalizedView`, `Action.PersonalizedViewsSharedWithYouTab`, `Action.MakePersonalizedViewPublic`, and `Action.DeletePersonalizedView`. For more information, see xref:embed-action-ref.adoc[Action IDs].#
* #Host events: `HostEvent.SharePersonalizedView`, `HostEvent.DeletePersonalizedView`, and `HostEvent.SetPersonalizedViewPublic`. For more information, see xref:events-hostEvents.adoc#pv-host-events[Personalized view host events].#
* #Embed event: `EmbedEvent.SharePersonalizedView`. For more information, see xref:event-embedEvents.adoc#pv-share-event[Personalized view sharing event].#
