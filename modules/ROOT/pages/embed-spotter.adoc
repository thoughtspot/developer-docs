Using the customization settings available in the SDK for each Spotter version, you can configure the Spotter interface to suit the needs of your embedding application.\n\n== Before you begin\n\nTo embed Spotter, you need the following access and setup:\n\n* Access to a ThoughtSpot instance with the Spotter feature. If you want a specific version of Spotter enabled, work with your ThoughtSpot administrator to enable the xref:embed-ai-analytics.adoc#_feature_status_and_availability_in_embed_mode[required features and settings] on your instance.\n* Your host application domain is added to xref:security-settings.adoc[ThoughtSpot CSP and CORS allowlists].\n* Your application project has access to the xref:api-changelog.adoc[latest version of the Visual Embed SDK].\n\n[NOTE]\n====\nFor Spotter embedding that uses cookieless authentication, use Visual Embed SDK version 1.45.0 or later with ThoughtSpot Cloud version 26.2.0.cl or later. To enable proactive token refresh, set the `refreshAuthTokenOnNearExpiry` parameter to `true`. +\nSpotter workflows may run longer at times. To prevent authorization errors, set the authentication token expiration to at least 10 minutes.\n====\n\n== Import the SDK package\nImport the `SpotterEmbed` SDK library to your application environment:\n\n**npm**\n[source,JavaScript]\n----\nimport {\n    SpotterEmbed,\n    AuthType,\n    init,\n    prefetch,\n    EmbedEvent,\n    HostEvent\n} from '@thoughtspot/visual-embed-sdk';\n----\n\n**ES6**\n[source,JavaScript]\n----\n<script type=\"module\">\n    import {\n        SpotterEmbed,\n        AuthType,\n        init,\n        prefetch,\n        EmbedEvent,\n        HostEvent\n    } from 'https://cdn.jsdelivr.net/npm/@thoughtspot/visual-embed-sdk/dist/index.js';\n</script>\n----\n\n== Initialize the SDK\n\nTo initialize the SDK, the following information is required:\n\n* `thoughtSpotHost` +\nThe xref:faqs.adoc#tsHostName[hostname] of your ThoughtSpot application instance.\n* `authType` +\nAuthentication type. For testing purposes, you can use `AuthType.None`. For information about other authentication options, see xref:embed-authentication.adoc[Authentication].\n\n[source,JavaScript]\n----\ninit({\n    thoughtSpotHost: 'https://your-thoughtspot-host', // Replace with your ThoughtSpot application URL\n    authType: AuthType.None, // Use the appropriate AuthType for your setup\n});\n----\n\n== Create an instance of the SpotterEmbed object\n\nCreate an instance of the `SpotterEmbed` object.\n\nIf you are embedding the Spotter Classic or Spotter 2 experience, the data source ID is required. **Code sample for embedding SpotterX experience**

    [source,JavaScript]
    ----
    import {
        SpotterEmbed,
        AuthType,
        init,
        EmbedEvent,
        HostEvent
    } from '@thoughtspot/visual-embed-sdk';

    // Initialize the ThoughtSpot Visual Embed SDK
    init({
        thoughtSpotHost: 'https://your-thoughtspot-host',
        authType: AuthType.None,
    });

    function showLoader() {
        // Show loading indicator
    }

    function hideLoader() {
        // Hide loading indicator
    }

    const container = document.getElementById('ts-embed');
    if (container) {
        const spotterEmbed = new SpotterEmbed(container, {
            frameParams: {
                height: '100%',
                width: '100%',
            },
            worksheetId: 'your-worksheet-id', // For Auto mode, specify 'auto_mode'
            spotterVersion: SpotterVersion.SpotterX, // Enable SpotterX
            //... other configuration attributes
        });

        // Register event listeners
        spotterEmbed.on(EmbedEvent.Init, showLoader);
        spotterEmbed.on(EmbedEvent.Load, hideLoader);

        // Render the SpotterEmbed
        spotterEmbed.render();
    }
