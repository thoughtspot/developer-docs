    === SpotterX experience
    [.version-badge.new]#26.11.0.cl#

    SpotterX is the next-generation Spotter experience in embedded views. To enable SpotterX, set the `spotterVersion` property to `SpotterVersion.SpotterX` in your embed configuration.

    [source,JavaScript]
    ----
    const spotterEmbed = new SpotterEmbed(document.getElementById('ts-embed'), {
        spotterVersion: SpotterVersion.SpotterX,
        worksheetId: 'your-worksheet-id',
        //...other attributes
    });
    ----

    SpotterX provides a redesigned conversational interface with the following features:

    * Improved chat layout and user interaction flow
    * Enhanced branding controls for text, labels, and icons
    * Instance-level branding behavior controls
    * Consistent configuration across Spotter, Liveboard, and full app embed contexts
    * Full support for `EmbedEvent` and `HostEvent` lifecycle controls

    [NOTE]
    ====
    SpotterX is opt-in. Existing Spotter embeds are unaffected unless you explicitly set `spotterVersion` to `SpotterVersion.SpotterX`. To roll back, set `spotterVersion` to `SpotterVersion.Spotter3` and re-render the component.
