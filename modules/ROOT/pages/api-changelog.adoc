    ===== SpotterX embed support
    You can now embed the SpotterX experience using the `SpotterEmbed`, `LiveboardEmbed`, or `AppEmbed` components. Set `spotterVersion` to `SpotterVersion.SpotterX` to enable the next-generation Spotter interface with improved chat layout, enhanced branding controls, and consistent configuration across all embed contexts.

    For more information, see xref:embed-spotter.adoc[Embed Spotter experience] and xref:customize-spotter-embed.adoc[Customize the Spotter embed view].

    |[tag greenBackground]#NEW#
    a|
    [discrete]
    ===== Host-controlled tooltip rendering
    The SDK now supports host-controlled tooltip rendering for embedded charts. Use the `onTooltipShow` callback to intercept the default tooltip and render a custom tooltip in your host application. The callback receives the tooltip data (column names, values, and point metadata), and you can return custom HTML content or suppress the tooltip entirely.

    For more information, see xref:customize-spotter-embed.adoc[Customizing charts in embedded views].

    |[tag greenBackground]#NEW#
    a|
    [discrete]
    ===== Programmatic Liveboard filter overrides [beta betaBackground]^Beta^
    You can now apply filter overrides to Liveboard visualizations programmatically through URL parameters. This allows host applications to set persistent filter states on embedded Liveboards without requiring user interaction.
