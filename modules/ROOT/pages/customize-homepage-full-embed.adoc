= Customize home page experience
:toc: true
:toclevels: 1

:page-title: Customize home page experience
:page-pageid: customize-homepage-experience
:page-description: Customize the home page experience by including or excluding specific modules and arranging them as needed in full application embedding

Developers can customize the home page experience in full application embedding to show either the modular home page experience or the focused home page experience, using the `homePage` attribute in the `discoveryExperience` object.

== Home page customization settings
The following customization settings are available in the SDK to configure the home page experience for the embedding application users:

* `HomePage.ModularWithStylingChanges` (Default) +
Enables the modular home page experience with customizable components, styling options, and enhanced layout. This experience includes charts in the **Watchlist** module that are arranged horizontally. Each chart includes menu actions to remove the KPI charts from the watchlist and create alerts, and allows drag-and-drop reordering.

* `HomePage.Focused` +
Enables the focused home page experience, which consolidates the **Watchlist** and **Recents** sections into a single, focused view. +

To customize the layout and visibility of the home page contents, the SDK provides the following settings:

[width="100%", cols="5,^3,^3"]
[options="header"]
|====
|Feature |Modular homepage experience |Focused homepage experience
|`hideHomepageLeftNav` +
Hides the left navigation panel on the home page.
|[tag greenBackground tick]#✓# Supported
|[tag greenBackground tick]#✓# Supported
|`hiddenHomepageModules` +
Hides specific modules on the home page.
|[tag greenBackground tick]#✓# Supported
|[tag redBackground tick]#x# Not supported
|`reorderedHomepageModules` +
Reorders modules on the home page.
|[tag greenBackground tick]#✓# Supported
|[tag redBackground tick]#x# Not supported
|`homePageModules` +
Specifies which modules to show on the home page.
|[tag greenBackground tick]#✓# Supported
|[tag redBackground tick]#x# Not supported
|`homePageSearchBarMode` +
Sets the search experience on the home page.
|[tag greenBackground tick]#✓# Supported
a|[tag redBackground tick]#x# Not supported +
If Spotter is enabled on your instance, the Spotter interface is set as the default experience in the focused home page layout.
|====

[#_modular_home_page_experience]
== Modular home page experience
By default, the `homePage` attribute is set to `HomePage.ModularWithStylingChanges` in the `discoveryExperience` object. This enables the modular layout, which includes components such as Search, Spotter (if Spotter is enabled), Watchlist, Library, Trending, and Learning in home page view.

* The **Search** module is displayed by default in the embed view. If Spotter is enabled in your instance, you can configure the xref:customize-homepage-full-embed.adoc#_search_experience_on_home_page[home page search bar experience] to display the **Spotter** module and the prompt.
* The charts in the **Watchlist** module are arranged horizontally. Each chart includes menu actions to remove the KPI charts from the watchlist and create alerts, and allows drag-and-drop reordering.
* The **Trending** module displays Liveboards and Answers trending over the last 15 days, or based on overall views, or both.
* The **Library** module displays the objects available to the user.

[#_focused_home_page_experience]
== Focused home page experience
The focused home page provides a contemporary experience that highlights the most relevant content immediately. It provides quick access to the Spotter interface and consolidates the **Watchlist KPIs** and **Recents** sections into a unified, focused layout.

To enable this layout in your embed, set the `homePage` attribute to `HomePage.Focused` in the `discoveryExperience` object.

[NOTE]
====
The focused home page experience requires Spotter to be enabled on your instance. If Spotter is not enabled, the embed always renders the modular home page experience, regardless of the `homePage` value set in `discoveryExperience`.
====

[source,JavaScript]
----
// Import required components and enums
import {
    AppEmbed,
    HomePage // Enum for home page experience settings
} from '@thoughtspot/visual-embed-sdk';

const embed = new AppEmbed("#embed", {
     discoveryExperience: {
         homePage: HomePage.Focused, // Enable focused home page experience
     },
     showPrimaryNavbar: true,
     //... other embed view configuration attributes
});
----

== Customizing home page modules
If you are using the modular home page experience, you can hide specific modules or change the order of the modules using the xref:AppViewConfig.adoc#_hiddenhomepagemodules[hiddenHomepageModules] and xref:AppViewConfig.adoc#_reorderedhomepagemodules[reorderedHomepageModules] configuration attributes in the SDK.

Both the `hiddenHomepageModules` and `reorderedHomepageModules` properties require you to specify the home page modules that you want to hide or reorder in the `HomepageModule[]` array. Valid values include:

[width="100%", cols="3,6"]
[options="header"]
|====
|Value |Description
|`HomepageModule.Watchlist` |The **Watchlist** module showing the objects added to the user's watchlist.
|`HomepageModule.MyLibrary` |The **My Library** module showing user's content.
|`HomepageModule.Learning` |The **Learning** module with onboarding content.
|`HomepageModule.Trending` |The **Trending** module showing trending content.
|`HomepageModule.Search` |The **Search** module showing the object search bar.
|`HomepageModule.Favorite` |The **Favorites** list showing the user's favorite objects in the left navigation panel.
|====


Example::

[source,javascript]
----
import {
    AppEmbed, // Main class to embed the full ThoughtSpot app
    HomePage, // Enum for home page experience settings
    HomepageModule // Enum for home page modules
} from '@thoughtspot/visual-embed-sdk';

const embed = new AppEmbed("#embed", {
    discoveryExperience: {
        homePage: HomePage.ModularWithStylingChanges, // Enables the modular home page.
    },
    // Hide modules from the home page
    hiddenHomepageModules: [
        HomepageModule.Learning,
        HomepageModule.Trending
    ],
    // Custom order for visible modules
    reorderedHomepageModules: [
        HomepageModule.Search,
        HomepageModule.Favorite,
        HomepageModule.Watchlist,
        HomepageModule.MyLibrary
    ],
    //... other view configuration properties
});
----

[#_search_experience_on_home_page]
== Customize the search module on the home page
You can set the search experience on the home page to function as an object search bar that allows finding popular objects, or as an AI search interface that allows natural language queries or Spotter sessions. You can also choose to hide it from the home page. This setting applies only to the modular home page experience (`HomePage.ModularWithStylingChanges`)—the focused home page experience always uses Spotter search by default.

To configure your preference, specify the following values in the `homePageSearchBarMode` attribute.

[width="100%", cols="6,8"]
[options="header"]
|====
|Search bar mode|Description
|`HomePageSearchBarMode.AI_ANSWER` |
Enables the Spotter search module that allows you to ask questions in natural language.
|`HomePageSearchBarMode.OBJECT_SEARCH` |Enables object search that allows users to find objects from the library. Default experience in the modular home page layout. To use Spotter search, set `HomePageSearchBarMode.AI_ANSWER`.
|`HomePageSearchBarMode.NONE` a| Hides the search bar on the home page. Note that it only hides the Search bar on the **Home** page and doesn't affect the Object Search bar visibility on the top navigation bar.

|====

=== Example
The following example shows a code snippet to set the home page search bar mode to Spotter or AI search:

Modular home page experience::

[source,javascript]
----
import {
    AppEmbed,
    HomePage, // Enum for home page experience settings
    HomePageSearchBarMode // Import the enum for search bar mode options
} from '@thoughtspot/visual-embed-sdk';

const embed = new AppEmbed("#embed", {
    discoveryExperience: {
        homePage: HomePage.ModularWithStylingChanges // Enable modular home page experience
    },
    // Set the home page search bar to show the Spotter / AI search bar
    homePageSearchBarMode: HomePageSearchBarMode.AI_ANSWER
    // Other view configuration attributes
});
----
