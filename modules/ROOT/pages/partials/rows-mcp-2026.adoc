===== Step headings in `get_session_updates` responses

Spotter now reports each step it works through while processing a question. `get_session_updates` returns these as `session_update` objects with `type: "step_notification"` and a short heading in the `text` field, such as `Searching data models` or `Running query`. xref:mcp-server-changelog.adoc#_step_headings_in_get_session_updates_responses[Learn more →]

===== Full tool response via URL flag

You can now receive the raw Spotter event stream from `get_session_updates` by appending `enable-raw-session-updates=true` to your MCP endpoint URL. The full response includes granular metadata about Spotter's internal tool calls, such as the columns in the data model used to answer the question, formulas, parameters, and subqueries. xref:mcp-server-changelog.adoc#_full_tool_response_via_url_flag[Learn more →]

===== SpotterCode authentication and workflow execution

SpotterCode now supports authenticated sessions with your ThoughtSpot instance. When connecting your MCP client to the SpotterCode endpoint, you are now prompted to log in using your organization's identity provider. After authentication, SpotterCode can make ThoughtSpot API calls on your behalf. For more information, see the documentation on xref:spottercode.adoc#_mcp_server_endpoints[SpotterCode MCP Server] and xref:spottercode-integration.adoc#_authenticate_spottercode[Authenticating SpotterCode].

===== Org switching tools

The OAuth MCP Server endpoints support new MCP tools to discover the user's current Org and allow multi-Org users to switch to another Org mid-session without logging out or re-authenticating: `list_orgs` returns the Orgs the account is currently an active member of, and `switch_org` switches the active Org for the current session. These tools are not available on Bearer-token connections. xref:mcp-server-changelog.adoc#_org_switching_tools[Learn more →]

===== MCP Server URL changes and API versioning

[.version-badge.breaking]#Breaking# Spotter MCP Server URLs now support date-based versioning, defined using the `?api-version=YYYY-MM-DD` parameter. URLs without the API version always point to the latest version and may introduce new tools — pin your integration to a tested version using `?api-version={YYYY-MM-DD}`.

===== SpotterCode extension for IDEs

ThoughtSpot introduces SpotterCode, an AI-powered Model Context Protocol (MCP) extension for Integrated Development Environments (IDEs) such as Cursor, Visual Studio Code, and Claude Code. When integrated, SpotterCode enables the AI agent in the IDE to access ThoughtSpot SDKs and API documentation resources and provide in-context coding assistance to developers embedding ThoughtSpot content within their applications.

SpotterCode is available as an Early Access feature and can be integrated with development environments that support MCP servers and tools. For more information, see xref:spottercode.adoc[SpotterCode], xref:spottercode-integration.adoc[Integrating SpotterCode in IDEs], and xref:spottercode-prompt-guide.adoc[SpotterCode prompting guide].
