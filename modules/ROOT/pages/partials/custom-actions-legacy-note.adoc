[IMPORTANT]
====
The legacy workflows for creating, assigning, and managing custom actions through the ThoughtSpot UI and REST APIs are deprecated from ThoughtSpot Cloud 26.12.0.cl. The *Custom actions* menu and page are no longer available in the UI. Custom actions that you created using the UI workflows or REST APIs continue to work until June 2027.

ThoughtSpot recommends using xref:code-based-custom-actions.adoc[code-based custom actions] in the Visual Embed SDK. For more information, see xref:deprecated-features.adoc#customActions[Custom actions deprecation].
====
