For information about new features and enhancements available for embedded analytics, see xref:whats-new.adoc[What's New].\n\n== Version 26.11.0.cl, November 2026

    === Org-level API rate limiting enforced
    The Org-level rate limit of 50 requests per second (RPS) per Org is now enforced for all public REST API endpoints on instances with Orgs enabled. This limit was announced in 26.10.0.cl and operates independently of the existing cluster-level limit of 100 RPS per client IP. Requests exceeding the Org-level limit receive an `HTTP 429: Too Many Requests` response.

    For more information, see xref:about-rest-apis.adoc#_rate_limits_for_api_requests[Rate limits for API requests].

    === Link Customization APIs
    ThoughtSpot introduces two REST API v2.0 endpoints for managing the URL templates used when ThoughtSpot generates shareable links.

    * `POST /api/rest/2.0/customization/links/search` +
    Retrieves the URL templates at the cluster level or for the Org the caller is signed in to.
    * `POST /api/rest/2.0/customization/links/update` +
    Updates the URL templates at the cluster level or for the caller's Org, using `REPLACE` to set templates or `RESET` to clear overrides.

    Supported link types include `LIVEBOARD_SHARE_URL`, `VISUALIZATION_SHARE_URL`, `ANSWER_SHARE_URL`, `SPOTIQ_ANALYSIS_URL`, `UNSUBSCRIBE_URL`, `GENERIC_URL`, and `CONVERSATION_SHARE_URL`.

    Requires `ADMINISTRATION` or `DEVELOPER` privilege.

    For more information, see xref:link-customization-api.adoc[Link Customization APIs].

    === Input Table APIs
    ThoughtSpot introduces REST API v2.0 endpoints for creating and managing input tables programmatically.

    * `POST /api/rest/2.0/input-tables/create` -- Creates an input table and links it to a model (worksheet).
    * `POST /api/rest/2.0/input-tables/{input_table_identifier}/columns/create` -- Adds editable columns to an existing input table.
    * `POST /api/rest/2.0/input-tables/{input_table_identifier}/delete` -- Deletes an input table and drops the physical CDW table.
    * `POST /api/rest/2.0/input-tables/{input_table_identifier}/columns/{column_identifier}/delete` -- Deletes a single column from an input table.
    * `POST /api/rest/2.0/input-tables/{input_table_identifier}/update` -- Writes rows into an input table using a keyed upsert (MERGE) operation.

    Requires `DATAMANAGEMENT` or `ADMINISTRATION` privilege. If RBAC is enabled, the `CAN_MANAGE_INPUT_TABLES` privilege is required.

    For more information, see xref:input-table-api.adoc[Input Table APIs].

    === Share Analyst API

    `POST /api/rest/2.0/ai/agent/analysts/{analyst_identifier}/share`::
    Updates share permissions on a Spotter Analyst for one or more principals (users or groups). Supports `READ_ONLY`, `MODIFY`, and `NO_ACCESS` share modes. Granting access also shares the Analyst's data sources with the recipient. Requires ownership of the Analyst, or `ADMINISTRATION` or `CAN_MANAGE_SPOTTER` privilege.
    +
    For more information, see xref:spotter-analyst-api.adoc[Spotter Analyst API].
