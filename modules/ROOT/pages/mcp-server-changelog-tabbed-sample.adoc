August 2026

[.release-notes-version]
2026-05-01
a|
Spotter now reports each step it works through while processing a question. `get_session_updates` returns these as `session_update` objects with `type: "step_notification"` and a short heading in the `text` field, such as `Searching data models` or `Running query`.

| MCP tools and integrations

a|
[.release-notes-date]
August 2026

[.release-notes-version]
2026-05-01
a|
You can now receive the raw Spotter event stream from `get_session_updates` by appending `enable-raw-session-updates=true` to your MCP endpoint URL. The full response includes granular metadata about Spotter's internal tool calls, such as the columns in the data model used to answer the question, formulas, parameters, and subqueries.

xref:mcp-server-changelog.adoc#_full_tool_response_via_url_flag[Learn more →]

a|
[.release-notes-date]
August 2026

[.release-notes-version]
2026-05-01
a|
A companion skill, `analyzing-data-with-thoughtspot` is now available for LLM clients that support skills, such as Claude. Installing the skill alongside the ThoughtSpot Spotter MCP Server improves how the client orchestrates ThoughtSpot MCP tools, including smarter routing of data questions, real-time progress narration during polling, and surfacing ThoughtSpot-generated visualization links instead of regenerating charts.

| Developer tooling

a|
[.release-notes-date]
July 2026

[.release-notes-version]
2026-05-01
a|
The OAuth MCP Server endpoints support new MCP tools to discover the user's current Org and allow multi-Org users to switch to another Org mid-session without logging out or re-authenticating: `list_orgs` returns the Orgs the account is currently an active member of, and `switch_org` switches the active Org for the current session. These tools are not available on Bearer-token connections.

xref:mcp-server-changelog.adoc#_org_switching_tools[Learn more →]
