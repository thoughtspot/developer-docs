    [#inputTables]
    == Input Tables
    [div tableContainer]
    --
    [width="100%", cols="2,1,4"]
    [options='header']
    |===
    |API endpoint | HTTP verb | Description

    |`/api/rest/2.0/input/tables/create`
    |POST
    |Creates an input table and links it to a ThoughtSpot model. Requires `DATAMANAGEMENT` or `ADMINISTRATION` privilege.

    |`/api/rest/2.0/input/tables/\{input_table_identifier}/update`
    |POST
    |Updates the name, description, or both of an input table. Requires `MODIFY` permission on the input table.

    |`/api/rest/2.0/input/tables/\{input_table_identifier}/delete`
    |POST
    |Deletes an input table. Requires `MODIFY` permission on the table's parent model.

    |`/api/rest/2.0/input/tables/columns/create`
    |POST
    |Adds a column to an existing input table. Requires `MODIFY` permission on the input table.

    |`/api/rest/2.0/input/tables/columns/\{column_identifier}/delete`
    |POST
    |Deletes a column from an input table. Requires `MODIFY` permission on the input table.
    |===
    --

    For more information, see xref:input-table-api.adoc[Input Table APIs].

    
    [#linkCustomization]
    == Link Customization
    [div tableContainer]
    --
    [width="100%", cols="2,1,4"]
    [options='header']
    |===
    |API endpoint | HTTP verb | Description

    |`/api/rest/2.0/customization/links/search`
    |POST
    |Returns the URL templates at the `CLUSTER` level or for the caller's Org. Templates define the URLs generated for shareable links, scheduled emails, and alert notifications.

    |`/api/rest/2.0/customization/links/update`
    |POST
    |Sets or resets URL templates. Use `REPLACE` to set a template or `RESET` to clear an Org-level override and fall back to the cluster default.
    |===
    --

    For more information, see xref:link-customization-api.adoc[Link Customization APIs].
