:page-title: Lesson 6 - Embed Natural Language Search
:page-pageid: tse-fundamentals__lesson-06
:page-description: ThoughtSpot has deprecated embedding Natural Language Search with SageEmbed. For AI Search and conversational analytics, embed Spotter.

[IMPORTANT]
====
ThoughtSpot has deprecated embedding Natural Language Search with `SageEmbed`. To embed AI Search and conversational analytics, ThoughtSpot strongly recommends using Spotter. For more information, see the xref:embed-spotter.adoc[Spotter embed] and xref:customize-spotter-embed.adoc[customization] documentation.
====
