= Listen for the click
:toc!:
:linkattrs:
:sectanchors:
:page-title: Listen for the click
:page-pageid: custom-actions__listen-for-click
:page-description: Handle EmbedEvent.CustomAction for the Flag to team action and inspect the context menu payload.

Every custom action click fires `EmbedEvent.CustomAction`. Register a listener before you call `render()`, check the action's ID, and log the payload:

[source,javascript]
----
liveboardEmbed.on(EmbedEvent.CustomAction, (payload) => {
  if (payload.data.id !== 'flag-to-team') return;
  console.log('Flag to team clicked:', payload.data);
});

liveboardEmbed.render();
----

Run the app, right-click a data point on any chart, choose *Flag to team*, and read the logged object before you write anything that depends on it. The payload is large, and its shape varies by target and position, so compare what you log with the xref:callback-response-payload.adoc[sample payloads].

For a context menu action, look for `contextMenuPoints.clickedPoint`. It holds the point the host right-clicked:

* `selectedAttributes` are the labels, such as `Month = Aug 2026`.
* `selectedMeasures` are the numbers, such as `Bookings = 412`.
