= Troubleshooting
:toc!:
:linkattrs:
:sectanchors:
:page-title: Troubleshooting
:page-pageid: custom-actions__troubleshooting
:page-description: Fix common issues with code-based custom actions on an embedded Liveboard.

[cols="2,3", options="header"]
|===
| Symptom | Action

| The action doesn't appear in the right-click menu
| Make sure you're right-clicking a data point, such as a bar, a line point, or a table cell, not the chart's background or title. Then check that the GUID in `liveboardIds` is the SpotStay Liveboard's, and that you're using Visual Embed SDK 1.43.0 or later.

| The message shows empty or `undefined` values
| The payload shape differs from what the helper expects. Compare it with the payload you logged in xref:custom-actions-tutorial-step-02.adoc[Listen for the click].

| The wrong code runs on click
| Your listener isn't checking `payload.data.id`. Every custom action click arrives on the same `EmbedEvent.CustomAction` listener.

| The payload has no chart data
| The action is probably targeting `LIVEBOARD` instead of `VIZ`. Liveboard-target actions don't include chart data. If you need chart data from a Liveboard action, fetch it separately with `POST /api/rest/2.0/metadata/liveboard/data`.

| Nothing changes after a code edit
| Disable the browser cache (*DevTools* > *Network* > *Disable cache*) and reload before you debug further.
|===
