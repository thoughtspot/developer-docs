= Register the action
:toc!:
:linkattrs:
:sectanchors:
:page-title: Register the action
:page-pageid: custom-actions__register-action
:page-description: Register a Flag to team callback custom action in the right-click menu of every chart on the bookings Liveboard.

Register the *Flag to team* custom action by adding it to the `customActions` array of your existing `LiveboardEmbed`:

[source,javascript]
----
import {
  LiveboardEmbed,
  EmbedEvent,
  CustomActionsPosition,
  CustomActionTarget,
} from '@thoughtspot/visual-embed-sdk';

const liveboardEmbed = new LiveboardEmbed(container, {
  frameParams: { width: '100%', height: '100%' },
  liveboardId: '<bookings-liveboard-guid>',
  customActions: [
    {
      name: 'Flag to team',
      id: 'flag-to-team',
      target: CustomActionTarget.VIZ,
      position: CustomActionsPosition.CONTEXTMENU,
      metadataIds: { liveboardIds: ['<bookings-liveboard-guid>'] },
    },
  ],
});
----

Each property does one job:

[cols="1,3", options="header"]
|===
| Property | What it does

| `name`
| The label users see in the menu.

| `id`
| How your code recognizes this action when it's clicked. Every custom action arrives on the same event, so the ID is what routes it.

| `target: VIZ`
| Attaches the action to each chart, not to the Liveboard as a whole. This matters: a Liveboard-target action doesn't include chart data in its payload, so you wouldn't know what was flagged.

| `position: CONTEXTMENU`
| Puts the action in the right-click menu. A right-click sends only the clicked data point, which is exactly what a host means when they say "this number looks wrong."

| `metadataIds.liveboardIds`
| Limits the action to charts on the SpotStay Liveboard. Without it, the action appears on every chart in the embed.
|===

Actions defined in code are callback actions: ThoughtSpot fires an event to your app instead of calling a URL, so the flag never leaves your portal's control.

[TIP]
====
SpotterCode can also create this action on your ThoughtSpot instance. Ask:

[source,text]
----
"Find every visualization on Liveboard <Liveboard_Name>. Then create a callback custom
action named "Flag to team" with the reference flag-to-team, add it to the right-click
context menu on each of those visualizations, and make it visible to the <hosts-group>
group."
----
====

For all the properties and scoping options, see xref:code-based-custom-actions.adoc[Code based custom actions].
