Embed Spotter, ThoughtSpot's AI Analyst, with per-user usage limits, a usage counter, and tier-based upgrades, instead of building everything from scratch.

== The scenario

Imagine you're a full-stack developer at SpotStay, a short-term rental company.
You want to let hosts ask questions about their analytics, but you can't offer it for free.
Your company has decided to sell it as a paid add-on:

* *Starter*: 400 queries a month
* *Pro*: 750 queries a month
* *Enterprise*: 1,000 queries a month

A query is one question a host sends to the agent. Each host gets their own allowance, which resets at the start of each billing cycle.

By the end of this guide, you'll have a Spotter agent inside the SpotStay host portal.
It enforces each host's plan, shows how many queries they have left, and passes upgrades to your billing flow.

Follow along in code with the link:https://github.com/nrentz-ts/spottercode[SpotStay app on GitHub, window=_blank].

[#before-you-begin]
== Before you begin

Make sure you have the following:

* *ThoughtSpot access*: Developer or Admin privilege on a ThoughtSpot instance running 26.11.0.cl or later.
* *An admin service account*: A ThoughtSpot user with the cluster-level *Can administer ThoughtSpot* (`ADMINISTRATION`) privilege. Your backend uses this account to manage usage pools. `CAN_MANAGE_SPOTTER` and Org administrator privileges are not enough.
* *Visual Embed SDK v1.53.0 or later* in your project. Earlier versions don't support the usage counter.
* *Security settings*: Your embedding application domains added to the CSP and CORS allowlists on the *Develop* > *Customizations* > *Security Settings* page. For details, see xref:getting-started.adoc[Set up ThoughtSpot to start embedding].
* *Trusted domains for theme assets*: If your theme references externally hosted fonts, images, or stylesheets, add those source domains as trusted domains under *Develop* > *Security Settings*.
* *SpotterCode*: The SpotterCode MCP server connected to your IDE. For details, see xref:build-embed-app-with-spottercode-step-01.adoc[Set up SpotterCode].
* *A billing system that owns your plans*: ThoughtSpot enforces and displays the limit. Your app decides which plan a host is on and charges for it. This guide uses Stripe.

The Spotter usage data APIs used in this guide are in Beta. Breaking changes may be introduced before they become Generally Available (GA).
