= Brand it as your own agent
:toc!:
:linkattrs:
:sectanchors:
:page-title: Brand it as your own agent
:page-pageid: monetize-spotter__brand-your-agent
:page-description: Rename the embedded Spotter agent to Stella, replace ThoughtSpot branding on answer cards, and apply the SpotStay theme.

Hosts shouldn't see "Spotter" or ThoughtSpot branding. They should meet Stella, SpotStay's booking assistant, styled like the rest of the portal.

Ask SpotterCode to rename and restyle the embed:

[source,text]
----
"Rebrand my Spotter embed as "Stella", SpotStay's booking assistant. Replace "Spotter"
with "Stella" in all UI text, replace the ThoughtSpot label on answer cards with
"SpotStay", hide the ThoughtSpot logo on those cards, and apply the SpotStay theme."
----

Generated output in your codebase:

[source,javascript]
----
import { init, SpotterEmbed } from '@thoughtspot/visual-embed-sdk';
import spotstayTheme from './theme/spotstay-theme.json';

init({
  // ...thoughtSpotHost, authType, and getAuthToken as before
  customizations: {
    style: {
      customCSS: {
        variables: {
          ...spotstayTheme,
          '--ts-var-root-font-family': 'Poppins, Helvetica, Arial, sans-serif',
          '--ts-var-button--primary-background': '#E2574C',
          '--ts-var-spotter-prompt-background': '#FDF0EE',
          '--ts-var-spotter-input-background': '#FFFFFF',
        },
      },
    },
    content: {
      strings: {
        'Spotter': 'Stella',
      },
    },
  },
});

const spotterEmbed = new SpotterEmbed('#ts-embed', {
  worksheetId: 'your-bookings-model-id',
  disableSourceSelection: true,
  spotterChatConfig: {
    toolResponseCardBrandingLabel: 'SpotStay', // replaces the "ThoughtSpot" prefix
    hideToolResponseCardBranding: true,        // hides the ThoughtSpot logo
  },
});
----

For more customization options, see xref:customize-spotter-embed.adoc[Customize the Spotter embed view], xref:customize-spotter-chat-experience.adoc[Customize the Spotter chat experience], and xref:customize-css-styles.adoc[CSS variables reference].
