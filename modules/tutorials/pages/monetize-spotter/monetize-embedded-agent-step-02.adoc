[#allowlist-domain]
== Allowlist the portal domain

Ask SpotterCode to allowlist the portal's domain:

[source,text]
----
"Add https://app.spotstay.com to the CORS allowlist and to the CSP visual-embed-hosts
list at cluster scope."
----

[#token-endpoint]
== Sign hosts in with trusted authentication

Turn on trusted authentication under *Develop* > *Customizations* > *Security Settings*, and store the secret key in your server's environment. Then ask SpotterCode for a token endpoint:

[source,text]
----
"Write a Node endpoint GET /api/ts-token that gets a ThoughtSpot full-access token for
the logged-in host using trusted authentication. Create the user on first login and add
them to the group for their current plan. Read the secret key from the environment."
----

Generated output in your codebase:

[source,javascript]
----
const TS_HOST = process.env.TS_HOST; // for example, https://spotstay.thoughtspot.cloud

app.get('/api/ts-token', requireLogin, async (req, res) => {
  const r = await fetch(`${TS_HOST}/api/rest/2.0/auth/token/full`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      username: req.user.id,
      email: req.user.email,
      display_name: req.user.name,
      secret_key: process.env.TS_SECRET_KEY,
      auto_create: true,
      group_identifiers: [planGroup(req.user.plan)], // for example, 'SpotStay Starter'
    }),
  });
  if (!r.ok) return res.sendStatus(502);

  const { token } = await r.json();
  res.send(token);
});
----

For more information, see xref:trusted-auth-secret-key.adoc[Trusted authentication with a secret key].

[#embed-spotter]
== Embed Spotter

Now ask SpotterCode to embed Spotter on the Bookings Model:

[source,text]
----
"Embed Spotter on the Bookings page of the portal, using the "Bookings" Model as the
data source."
----

Generated output in your codebase:

[source,javascript]
----
import { init, AuthType, SpotterEmbed } from '@thoughtspot/visual-embed-sdk';

init({
  thoughtSpotHost: 'https://your-instance.thoughtspot.cloud',
  authType: AuthType.TrustedAuthTokenCookieless,
  autoLogin: true,
  getAuthToken: () => fetch('/api/ts-token').then((r) => r.text()),
});

const spotterEmbed = new SpotterEmbed('#ts-embed', {
  frameParams: { width: '100%', height: '100%' },
  worksheetId: 'your-bookings-model-id',
  disableSourceSelection: true,
});

spotterEmbed.render();
----
