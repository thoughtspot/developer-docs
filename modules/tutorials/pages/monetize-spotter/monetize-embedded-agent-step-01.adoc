= Map your plans to user groups
:toc!:
:linkattrs:
:sectanchors:
:page-title: Map your plans to user groups
:page-pageid: monetize-spotter__map-plans-to-groups
:page-description: Create a ThoughtSpot group for each SpotStay plan and give every plan read access to the Bookings Model.

Each plan becomes a ThoughtSpot group. The group identifies which plan a host is on and gives them access to the data that Spotter answers from.

[cols="1,2,1", options="header"]
|===
| Plan | Customers in the group | Queries per month

| SpotStay Starter
| Customer 1, Customer 2
| 400

| SpotStay Pro
| Customer 3
| 750

| SpotStay Enterprise
| Customer 4, Customer 5
| 1,000
|===

[#create-groups]
== Create the groups

Ask SpotterCode in your IDE to create the groups:

[source,text]
----
"Create three groups: "SpotStay Starter", "SpotStay Pro", and "SpotStay Enterprise",
each with the "Can use Spotter" privilege and without "Has developer privilege"."
----

[#share-model]
== Share the data

Then ask SpotterCode to give every plan read access to the data:

[source,text]
----
"Share the "Bookings" Model with all three SpotStay groups as read-only."
----

[#plans-file]
== Keep the plans in one file

Keep the plan details in one typed file, so the token endpoint, the usage helper, and the webhook all use the same values:

[source,typescript]
----
// src/plans.ts
export type Plan = 'starter' | 'pro' | 'enterprise';

export const PLANS: Record<Plan, number> = {
  starter: 400,
  pro: 750,
  enterprise: 1000,
};

export const PLAN_GROUPS: Record<Plan, string> = {
  starter: 'SpotStay Starter',
  pro: 'SpotStay Pro',
  enterprise: 'SpotStay Enterprise',
};

export const planGroup = (plan: Plan): string => PLAN_GROUPS[plan];
----

[#why-not-group-pools]
== Why the allowance doesn't live on the group

The groups don't hold the query allowance. A usage pool belongs to the entire group: a 400-query Starter pool splits across every Starter host. Each host needs their own 400 queries, so the allowance lives in a per-host pool, which you set up in xref:monetize-embedded-agent-step-04.adoc[Add the usage meter].

To learn more about monetizing Spotter in embedded apps, see link:https://thoughtspot.com/blog/spotter-usage-limits-embedded[Spotter usage limits for embedded apps, window=_blank] and xref:spotter-usage-limits.adoc[Manage Spotter usage limits].
