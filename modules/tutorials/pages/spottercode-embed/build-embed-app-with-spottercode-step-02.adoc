:page-description: Prompt SpotterCode to generate the React code for embedding a ThoughtSpot Liveboard.

With `init()` in place, the first goal is to get a host's listing-performance Liveboard rendering inside the SpotStay portal.
Write a specific prompt rather than a vague one:

[source]
----
I want to embed a ThoughtSpot Liveboard showing listing performance in my React app.
Use the available tools to get this information and generate the embed code.
----

What SpotterCode needs to finish the job: the ThoughtSpot host URL (already set in `init()`), the Liveboard GUID (grabbed from the Developer Playground), and confirmation of the auth type you're already using.

SpotterCode returns:

[source,javascript]
----
import {
  LiveboardEmbed,
  useEmbedRef,
} from '@thoughtspot/visual-embed-sdk/react';

// Assumes init() has already run at the app root — see the intro
const HostDashboard = () => {
  const embedRef = useEmbedRef();

  return (
    <LiveboardEmbed
      ref={embedRef}
      liveboardId="YOUR_LIVEBOARD_GUID" // <1>
    />
  );
};

export default HostDashboard;
----
<1> Replace with the GUID from the Developer Playground.
