:page-title: Step 3: Make it host-specific
:page-pageid: spottercode-embed__step-03
:page-description: Prompt SpotterCode to add a runtime filter so each host sees only their own listing data.

A shared Liveboard shows every listing on the platform.
You need each host to see only their own.
Prompt for a runtime filter scoped to the logged-in host:

[source]
----
Show a code example for embedding a Liveboard with a runtime filter
where host_id equals the logged-in user's ID, using the Visual Embed SDK for React.
----

SpotterCode returns:

[source,javascript]
----
import {
  LiveboardEmbed,
  useEmbedRef,
  HostEvent,
  RuntimeFilterOp,
} from '@thoughtspot/visual-embed-sdk/react';

const HostDashboard = ({ hostId }) => {
  const embedRef = useEmbedRef();

  const onLiveboardRendered = () => {
    embedRef.current.trigger(HostEvent.UpdateRuntimeFilters, [
      {
        columnName: 'host_id',
        operator: RuntimeFilterOp.EQ,
        values: [hostId],
      },
    ]);
  };

  return (
    <LiveboardEmbed
      ref={embedRef}
      liveboardId="YOUR_LIVEBOARD_GUID"
      onLiveboardRendered={onLiveboardRendered}
    />
  );
};

export default HostDashboard;
----

[NOTE]
====
*Why this step matters for the course, not just the demo:* this is the moment your prompt has to carry business context ("the logged-in user's ID") that isn't in any doc.
SpotterCode generates the mechanism; you still supply the SpotStay-specific meaning.
