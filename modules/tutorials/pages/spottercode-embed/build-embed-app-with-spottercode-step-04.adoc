Dashboard shipped.
Now the second use case: hosts asking follow-up questions in their own words instead of hunting through Liveboard filters.

[source]
----
I want to embed ThoughtSpot Spotter below the dashboard so hosts can ask
follow-up questions about their listing data.
Use the available tools to get the information and generate the code.
----

SpotterCode returns:

[source,javascript]
----
import { SpotterEmbed } from '@thoughtspot/visual-embed-sdk/react';

const HostInsights = ({ hostWorksheetId }) => {
  return (
    <SpotterEmbed
      worksheetId={hostWorksheetId}
      hideSampleQuestions={false} // <1>
    />
  );
};

export default HostInsights;
----
<1> Sample questions are shown by default. Set `hideSampleQuestions={true}` to hide them.

Drop `HostInsights` directly under `HostDashboard` on the same portal page — same host-scoped worksheet, no separate auth flow to build.
