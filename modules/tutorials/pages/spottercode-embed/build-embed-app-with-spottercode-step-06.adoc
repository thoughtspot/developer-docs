:page-title: Step 6: Wire it to real data
:page-pageid: spottercode-embed__step-06
:page-description: Use SpotterCode to generate a REST API request that looks up the real worksheet ID for your data.

Everything so far used a placeholder worksheet ID.
You still need the actual worksheet ID for SpotStay's listing data — no need to dig through the ThoughtSpot UI by hand.

[source]
----
Generate a REST API request to find the worksheet ID for a data object
named 'SpotStay Listings', using ThoughtSpot REST API v2.
----

SpotterCode returns:

[source,shell]
----
curl -X POST 'https://your-thoughtspot-host/api/rest/2.0/metadata/search' \
  -H 'Authorization: Bearer <your_access_token>' \
  -H 'Content-Type: application/json' \
  -d '{
    "metadata": [{ "type": "LOGICAL_TABLE", "name_pattern": "SpotStay Listings" }],
    "record_size": 5
  }'
----

Replace `your-thoughtspot-host` with your instance hostname and `<your_access_token>` with a valid bearer token.
The response includes the model GUID. Copy it into your `SpotterEmbed` and `LiveboardEmbed` components.
