= Step 1: Set up SpotterCode in your IDE
:toc!:
:linkattrs:
:sectanchors:
:page-title: Step 1: Set up SpotterCode in your IDE
:page-pageid: spottercode-embed__step-01
:page-description: Connect SpotterCode to your IDE via MCP and verify it has access to the ThoughtSpot developer docs and REST API reference.

This guide assumes you're working in Claude Code.
Setup takes one of two paths.

== If your Claude account has Claude AI (web) access

. In Claude AI, go to *Customize* > *Connectors*.
. Click the *+* icon and select *Add custom connector*.
. Enter the server URL: `+https://spottercode.thoughtspot.app/mcp+`
. Click *Add*.
+
This syncs to Claude Code automatically — no separate configuration needed.

== Claude Code only, without web access

Run this from the CLI in your project directory:

[source,shell]
----
claude mcp add --transport http SpotterCode https://spottercode.thoughtspot.app/mcp
----

== Verify the connection

Open a chat in your project and ask a scoped question to confirm SpotterCode is connected:

[source]
----
Use SpotterCode to confirm you have access to the ThoughtSpot developer docs and REST API reference.
----

[NOTE]
====
*Same pattern in Cursor or VS Code:* the prompting workflow is identical once either is connected.

*Cursor:* one-click install from the Cursor Marketplace, or add the server URL in *Settings* > *Tools and MCP*.

*VS Code:* add the server via the Extensions view or workspace `mcp.json`, with GitHub Copilot or a compatible chat agent installed, so there's a chat agent to talk to.
====
