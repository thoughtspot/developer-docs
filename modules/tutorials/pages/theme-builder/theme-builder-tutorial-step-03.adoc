[#export-theme]
== Export the theme

Preview the theme in the right-hand pane, where you can see the styled components before you push anything to your app. When you're happy with the result, export the theme to add it to your codebase.

Click *Export JSON* in the top navigation, and then click *Copy JSON* to copy it to your clipboard, or *Export* to download the file.

The export is a set of ThoughtSpot CSS variables: `--ts-var-*` keys with your values. That JSON is the file you version-control. Commit it to your repository, for example as `theme/spotstay-theme.json`, so the theme has a source of truth outside Theme Builder.

[#apply-theme]
== Apply the theme in your app

Add the exported variables to `customizations.style.customCSS.variables` in your SDK initialization code:

[source,javascript]
----
import { init, AuthType } from '@thoughtspot/visual-embed-sdk';

const tsURL = 'https://your-instance.thoughtspot.cloud';

init({
  thoughtSpotHost: tsURL,
  authType: AuthType.None, // local development only; use trusted authentication in production
  customizations: {
    style: {
      customCSS: {
        variables: {
          // Application-wide
          '--ts-var-root-background': '#FAF8F5',
          '--ts-var-root-color': '#26292E',
          '--ts-var-root-secondary-color': '#6E7278',
          '--ts-var-root-font-family': 'Poppins, Helvetica, Arial, sans-serif',
          '--ts-var-root-text-transform': 'none',

          // Buttons
          '--ts-var-button-border-radius': '12px',
          '--ts-var-button--icon-border-radius': '12px',
          '--ts-var-button--primary-background': '#E2574C',
          '--ts-var-button--primary-color': '#FFFFFF',
          '--ts-var-button--primary--hover-background': '#C4463C',
          '--ts-var-button--secondary-background': '#FDF0EE',
          '--ts-var-button--secondary-color': '#C4463C',
          '--ts-var-button--secondary--hover-background': '#FBE3E0',

          // Liveboard and tiles
          '--ts-var-liveboard-layout-background': '#FAF8F5',
          '--ts-var-viz-background': '#FFFFFF',
          '--ts-var-viz-border-radius': '16px',
          '--ts-var-liveboard-tile-border-radius': '16px',
          '--ts-var-viz-title-color': '#26292E',
          '--ts-var-viz-description-color': '#6E7278',

          // Charts
          '--ts-var-axis-title-color': '#6E7278',
          '--ts-var-axis-data-label-color': '#6E7278',

          // Filter chips
          '--ts-var-chip-border-radius': '999px',
          '--ts-var-chip-background': '#FDF0EE',
          '--ts-var-chip-color': '#26292E',

          // Spotter
          '--ts-var-spotter-prompt-background': '#FDF0EE',
          '--ts-var-spotter-input-background': '#FFFFFF',
        },
      },
    },
    content: {
      strings: {
        'Spotter': 'Ask SpotStay', // matches the nav button copy
        'Liveboard': 'Dashboard',
        'Search data': 'Explore data',
      },
    },
  },
});
----

For the full list of variables, see xref:customize-css-styles.adoc[CSS variables reference]. To replace other UI text, see xref:customize-text-strings.adoc[Customize text strings]. For authentication options, see xref:embed-authentication.adoc[Authentication].
