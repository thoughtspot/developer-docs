= Generate the theme in AI mode
:toc!:
:linkattrs:
:sectanchors:
:page-title: Generate the theme in AI mode
:page-pageid: theme-builder__generate-theme-ai-mode
:page-description: Use Theme Builder's AI mode and your brand guidelines to generate a theme for an embedded Liveboard, then refine it with follow-up prompts.

Navigate to *Develop* > *Customizations* > *Theme Builder*.

. From the dropdown in the top navigation, pick the embedded component you're theming: Liveboard, Visualization, Search, Spotter, or full application. Theme the component your users see first. This guide starts with the Liveboard.
. Theme Builder opens in *AI mode*.
. Attach the brand guidelines document and send the following prompt:
+
[source,text]
----
"Use the attached SpotStay brand guidelines as the source of truth for this theme."
----

The embedded component re-renders as each change is applied, so you're reviewing the real component, not a swatch preview.

== Refine with follow-up prompts

Use follow-up prompts to refine the theme. Follow-up prompts work best when each one does one job. Try these:

[source,text]
----
"Update all buttons to a border radius of 12px, with white text on the primary brand
color, Coral #E2574C. Use #C4463C as the hover color."
----

[source,text]
----
"Set the tile corner radius to 16px."
----

[source,text]
----
"Set the application font family to Poppins, with a Helvetica, Arial, sans-serif
fallback and no text transform."
----

You now have a solid base to build on.

For more information, see xref:theme-builder.adoc[Theme Builder].
