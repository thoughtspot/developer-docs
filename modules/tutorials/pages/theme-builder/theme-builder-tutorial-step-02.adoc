:page-description: Fine-tune the AI-generated theme in Theme Builder's Manual mode, section by section.

Switch to *Manual mode* and expand the section you want to adjust.

Use the controls to fine-tune the styling. Each section targets a different part of the UI:

[cols="1,3", options="header"]
|===
| Section | What it styles

| Application level
| Global defaults for the whole app: background, text color, font, and capitalization. Most other sections inherit from these, so start here. *Segment Control* styles toggle-style button groups, such as *All* / *Answers* / *Liveboards*.

| Liveboard
| The Liveboard page: the header, the tiles that hold each chart (background, border, corners, padding, and title size), the page background, grouped tiles, note tiles, tabs, chips, and the edit bar. The *Column* settings control when the layout switches to fewer columns on smaller screens.

| Charts
| The charts themselves: background, rounded corners, shadow, title and description text, axis labels, and legends. This section also covers KPI charts, including the big number and the green and red change colors.

| Buttons
| Three button types: primary for main actions such as *Save*, secondary for supporting actions such as *Share*, and tertiary for minor actions such as *Undo*. Each type has colors for the normal, hover, and pressed states. Under *Other*, you can round the button corners.

| Filter/Parameter chips
| The small pill-shaped tags that show which filters or parameters are applied. You can set colors for the normal, hover, and selected states, plus corner roundness and an optional shadow.

| Menu
| Dropdown and right-click menus: background, text, hover color, selected item color, font, and capitalization.

| Modal dialogs
| Pop-up windows, such as *Pin to Liveboard*. You can color the header, body, and footer separately.

| Checkboxes
| Checkboxes in every state: normal, hover, checked, disabled, and error.

| Search data
| The search experience: the search bar, the suggestions dropdown, the side panels, and the controls for switching chart types.

| Spotter
| The background of Spotter's chat and prompt areas. Spotter's buttons and charts use the *Buttons* and *Charts* sections.

| Navigation bar
| The top bar and its *Search data* button. Applies only when you embed the full ThoughtSpot application.

| Home page
| The favorites cards and the KPI watchlist on the home page. Applies only when you embed the full ThoughtSpot application.
|===

[NOTE]
====
* AI mode and Manual mode work independently, so you can use whichever fits your workflow. Using both is optional.
* Changes made in Manual mode aren't overwritten by AI mode instructions unless you say so in the prompt.
* To apply a style that matches an image, upload the image as a standalone file, such as a PNG or JPEG. Theme Builder can't pick up visual styles from images embedded in a PDF; it reads only the text in a PDF.
* File uploads are limited to 10 MB per chat input.
* If you leave Theme Builder and come back later, your style changes are kept, but the chat history is cleared.

For more information, see xref:theme-builder.adoc[Theme Builder].
====
