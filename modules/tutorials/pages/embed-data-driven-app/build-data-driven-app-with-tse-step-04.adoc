:page-title: Step 4: Style it to match the portal
:page-pageid: embed-data-driven-app__step-04
:page-description: Use the AI Theme Builder to generate CSS variables and content strings that make the embed match the SpotStay portal.

A dashboard that looks like a different product breaks the self-serve, built-in feeling you're going for.
Start in the AI Theme Builder (*Develop* > *Customizations* > *Theme Builder*) — upload brand guidelines or describe them, watch a theme get generated, then fine-tune colors manually in Manual Mode.
Exporting gives you a set of CSS variables to drop straight into `init()`:

[source,javascript]
----
init({
  thoughtSpotHost: tsURL,
  authType: AuthType.None,
  customizations: {
    style: {
      customCSS: {
        variables: {
          '--ts-var-button--primary-background': '#0B5FFF',
          '--ts-var-root-color': '#1A1A1A',
          '--ts-var-root-background': '#FFFFFF',
          '--ts-var-spotter-prompt-background': '#F0F4FF',
        },
      },
    },
    content: {
      strings: {
        'Spotter': 'Ask SpotStay', // <1>
      },
    },
  },
});
----
<1> Renames the "Spotter" label to match the nav button copy in the portal.

For anything the CSS variables don't cover, `rules_UNSTABLE` lets you target specific elements with raw selectors.
Test those in the Playground first, since selectors can shift between ThoughtSpot releases while the CSS variables stay stable across versions.

[WARNING]
====
If you host fonts or icon sprites externally, that domain needs to go into `style-src` in Security Settings, or the browser silently blocks them.
This is one of those bugs that looks like nothing is wrong until you check the console.
====
