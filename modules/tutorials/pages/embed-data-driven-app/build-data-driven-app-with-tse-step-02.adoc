:page-description: Embed the bookings Liveboard, and optionally a single visualization from it, using the Liveboard ID from the Developer Playground.

Your first real milestone: the bookings Liveboard rendering inside the portal.
Grab the Liveboard ID from the Playground and drop it straight in:

[source,javascript]
----
function renderLiveboard() {
  const liveboardEmbed = new LiveboardEmbed(container, {
    frameParams: { width: '100%', height: '100%' },
    liveboardId: 'YOUR_LIVEBOARD_GUID', // <1>
  });

  liveboardEmbed.on(EmbedEvent.LiveboardRendered, () => {
    console.log('Liveboard rendered');
  });

  liveboardEmbed.render();
}
----
<1> Copy this value from the Developer Playground. Do not hand-type it.

If you only need one chart from that board rather than the whole thing. For example, just the occupancy-rate visualization for a smaller widget elsewhere in the portal, add a `vizId` alongside `liveboardId`, grabbed the same way from the Playground:

[source,javascript]
----
const vizEmbed = new LiveboardEmbed(container, {
  frameParams: { width: '100%', height: '100%' },
  liveboardId: 'YOUR_LIVEBOARD_GUID',
  vizId: 'YOUR_VIZ_GUID',
});
----

[TIP]
====
If the embed renders blank here: check the browser console first, then confirm `thoughtSpotHost` is correct and that the portal's domain is in the CSP allowlist.
See xref:build-data-driven-app-with-tse-summary.adoc#appendix-b[Appendix B] for the full checklist.
